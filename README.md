# WAYLO
### Smart Carpool Matching Platform

PoolMate is a carpooling platform designed to help commuters find people travelling on similar routes at similar times. It aims to make daily travel more affordable, convenient, and safer.

## Problem Statement

Many people travel alone even when others are going in the same direction. Finding people with matching routes, managing travel costs, and trusting new travel partners can be difficult.

## Our Solution

PoolMate aims to solve these problems through:

* **Smart Ride Matching:** Find rides based on route and departure time.
* **Cost Sharing:** Estimate travel costs based on distance.
* **Recurring Commutes:** Support regular daily or weekly travel plans.
* **Safety Features:** Highlight verified profiles and women-only ride options.
* **Seat Requests:** Allow users to request available seats.

## Features in Our Prototype

* Search rides by starting point, destination, date, and time.
* Filter rides using route overlap and women-only preferences.
* View sample driver profiles, ratings, available seats, and estimated fares.
* Try a simulated seat-booking request.
* Select recurring commute preferences.
* Responsive layout for desktop and mobile screens.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Alternatively, use the Live Server extension in VS Code.

## Current Limitations

This is an early-stage prototype. Ride information is sample data, matching uses predefined route-overlap values, and booking requests are simulated. A backend, database, live maps, and real user verification are not yet implemented.

## Future Scope

* Backend and database integration.
* User registration and login.
* Map-based route matching.
* Automatic fare splitting based on shared distance.
* Real recurring ride management.
* Secure booking and driver verification.

## Project Goal

To make everyday commuting more affordable, convenient, and safer by connecting people travelling in the same direction.
